===============================================
TẠO MIGRATION MỚI (Tương lai)
===============================================

File: migrations/V003__Your_Change.sql

BEGIN TRANSACTION;

IF NOT EXISTS (SELECT * FROM sys.columns 
              WHERE object_id = OBJECT_ID('Employees') 
              AND name = 'NewColumn')
BEGIN
    ALTER TABLE Employees ADD NewColumn NVARCHAR(100);
END

COMMIT TRANSACTION;

Sau đó: dotnet run
→ V003 tự động apply!
