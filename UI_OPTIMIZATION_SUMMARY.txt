───────────────────────────────────────────────────────────
 🎯 HOW TO USE
───────────────────────────────────────────────────────────

Option 1: Use optimized CSS only
────────────────────────────────
In _Layout.cshtml or _layoutNoHeader.cshtml:

<link href="/css/custom-optimized.css" rel="stylesheet">

Option 2: Use optimized layout (recommended)
─────────────────────────────────────────────
In _ViewStart.cshtml:

@{
    Layout = "_LayoutOptimized";
}

Option 3: Add performance optimizer
────────────────────────────────────
In layout file (before </body>):

<script src="/js/performance-optimizer.js"></script>

Usage in your code:
───────────────────
// Debounce search
const searchDebounced = PerformanceOptimizer.debounce(
    searchFunction, 
    300
);

// Throttle scroll
const scrollThrottled = PerformanceOptimizer.throttle(
    scrollHandler, 
    100
);

// Optimized AJAX
const data = await PerformanceOptimizer.optimizedAjax.get(
    '/api/employees'
);
